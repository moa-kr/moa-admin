# 모아 어드민 (MOA Admin)

포켓몬카드모아(`moa-kr/pokemoa`)와 회사복지모아(`moa-kr/bokjinabi`)의 공지·팝업, 탭·섹션 순서, 세부 문구를 한 화면에서 고치고 GitHub에 바로 커밋하는 운영자 콘솔입니다.

- **주소**: <https://moa-kr.github.io/moa-admin/> (검색엔진 비노출: `noindex, nofollow`)
- **저장 형식**: [`config/site-config.schema.json`](config/site-config.schema.json) · 설명서 [`SCHEMA.md`](SCHEMA.md)

## 쓰는 방법

1. 주소를 엽니다. **아이디·비밀번호** 칸이 나옵니다(기본 경로).
2. 아이디·비밀번호를 넣고 `90일 동안 로그인 유지`를 확인한 뒤 **로그인**을 누릅니다.
   - 로그인은 복지모아 서버(`https://bokjimoa.onrender.com/api/admin/login`)가 확인하고, 브라우저에는 **HMAC 서명 토큰**만 남습니다.
   - 비밀번호는 서버의 Render 환경변수(`ADMIN_LOGIN_ID`·`ADMIN_LOGIN_PW`)에만 있고 저장소에는 없습니다.
3. **불러오기**·**저장 및 사이트 반영**·**회사복지모아 문의 조회/삭제**는 모두 같은 서버(`/api/admin/repo-config`, `/api/admin/inquiries`)를 Bearer 토큰으로 부릅니다. GitHub PAT 은 서버(`ADMIN_GITHUB_PAT`)에만 있습니다.
4. ①~③ 에서 고치고 **저장 및 사이트 반영**을 누르면 서버가 설정 JSON을 저장소에 커밋하고, 곧 사이트에 반영됩니다.

**예비 경로** — 아이디 로그인이 막히면 아래 접힌 **‘고급: GitHub 토큰으로 직접 로그인’** 에서 PAT(+관리자 키 `x-sync-key`)로 들어갈 수 있습니다. 이 경로는 브라우저가 GitHub API 를 직접 부릅니다.

로그인 없이도 **데모(미리보기) 모드**로 화면과 미리보기를 그대로 써 볼 수 있습니다(저장만 잠김).

오른쪽(모바일에서는 ‘미리보기’ 버튼)의 **모바일 미리보기는 실제 사이트 그 자체**입니다. 라이브 사이트(`https://moa-kr.github.io/pokemoa/` · `https://bokjimoa.onrender.com/`)를 **390px 폭 `<iframe>`** 으로 띄우고 화면 폭에 맞춰 축소하며, 어드민에서 고친 **저장 전 draft 설정**을 `postMessage` 로 보내 새로고침 없이 그 자리에서 다시 그립니다(배너·팝업·탭 이동·탭/섹션 순서·숨김·문구·본문 모두).

- 어드민 → 사이트: `{ type: "moa-preview-config", config, activeTab, site }` 를 iframe 의 출처로 보냅니다(디바운스 120ms).
- 사이트 → 어드민: 로더가 `{ type: "moa-preview-ready" }`(준비됨) · `{ type: "moa-preview-applied" }`(반영 완료)를 보냅니다.
- **미리보기에서 고칠 곳을 누르면 그 입력칸으로 이동합니다**(2026-11-20, 어드민 `v=33` · 사이트 로더 `v4.3`). 미리보기 안의 문구(`data-copy`·`data-copy-html`), 섹션(`data-section`), 공지 배너·팝업 제목을 클릭하면 기본 링크 이동을 막고 `{ type: "moa-preview-focus", target: { kind, key|id } }` 를 어드민에 보냅니다. 어드민은 **문구 → ③ 문구 탭의 그 칸**, **섹션 → ② 탭·섹션의 그 섹션(편집기 펼침)**, **배너·팝업 → ① 공지·팝업**으로 전환한 뒤 그 입력칸으로 부드럽게 스크롤하고 포커스를 주며 **2.6초 노란 테두리 강조**(`.is-jump-target`)를 표시합니다. 모바일(세로 배치)에서는 덮고 있던 미리보기 패널을 먼저 닫아 아래 입력칸이 보이게 합니다. 미리보기 중에는 고칠 수 있는 요소에 점선 hover 표시가 붙습니다.
- 로더는 출처가 `https://moa-kr.github.io`(및 로컬 테스트 `localhost`·`127.0.0.1`) 일 때만 받습니다. 미리보기 중에는 방문자의 ‘다시 보지 않기’ 저장소를 건드리지 않고 팝업 기간도 무시합니다.
- 로딩 안내·지연(복지모아 Render 콜드스타트) 안내와 **다시 불러오기** 버튼이 있고, 복지모아는 CSP `frame-ancestors` 로 어드민 출처를 허용합니다(`server.js`).

**캐시 주의** — GitHub Pages 는 HTML 을 10분간 캐시합니다. 자산을 고치면 `index.html` 의 `?v=` 를 **반드시** 올리고(현재 `v=37`), 화면 왼쪽 위 배지의 빌드 번호로 지금 보고 있는 화면이 최신인지 확인합니다.

## 🎛️ 포케모아 팝업 관리 (2026-11-24 · v=37)

포켓몬카드모아 화면에 실제로 뜨는 **「팜사이즈 원더 안내」 팝업**(`assets/js/figure.js`)과 오른쪽 아래 **‘다시 보기’ 버튼**을 ① 공지·팝업 화면의 **팝업 관리 · 팜사이즈 원더 안내** 카드에서 그대로 제어합니다.

- **노출 ON/OFF** — 카드 오른쪽 스위치. 끄면 모달과 ‘다시 보기’ 버튼이 **모두** 사라집니다.
- **첫 방문 자동 열기 / 닫은 뒤 ‘다시 보기’ 버튼 / ‘오늘 하루 보지 않기’** — 각각 스위치로 켜고 끕니다.
- **이미지 위 배지 · 제목 위 작은 줄 · 제목 · 본문(줄바꿈 그대로) · 버튼 문구 · ‘다시 보기’ 문구**
- **버튼을 누르면** — `재고 찾기(지도)`(지금과 같이 피규어 재고 조회) · `탭 열기`(아래 ‘버튼 대상’에 `map`·`home`·`schedule`·`guide`·`trends`) · `링크 열기`(https 주소) · `닫기만`
- **기간** — 시작일·종료일(비우면 항상). 저장 값은 `site-config.json` 의 **`figurePopup`** 이고 형식은 [`SCHEMA.md`](SCHEMA.md) 에 있습니다.

**반영 속도** — 포케모아(`site-config-loader.js` **v4.4**)는 화면을 그릴 때 복지모아 서버의 공개 설정 API `GET https://bokjimoa.onrender.com/api/site-config?site=pokemoa` 를 **먼저** 읽습니다. 이 서버는 어드민이 저장하면서 커밋한 설정을 메모리에 들고 있어 **GitHub Pages 빌드(30초~1분)를 기다리지 않고** 새 팝업이 바로 내려갑니다. API 가 2.5초 안에 답하지 못하거나 503이면 사이트는 자기 저장소의 `assets/config/site-config.json` 으로 **조용히 폴백**합니다(화면은 그대로). 공개되는 값은 이미 공개 저장소에 있는 설정뿐이고 토큰·비밀번호는 들어가지 않습니다.

## 💰 개인 재무 (2026-11-24 · v=39) — 엑셀 가계부 구조 v2 + 실시간 자동 분석

관리자 로그인 뒤에만 열리는 **`💰 개인 재무`** 탭입니다(위 탭 줄 맨 오른쪽, 헤더의 같은 이름 버튼도 이 탭을 엽니다). 여조원 님의 **월 현금흐름 · 대출 현황 · 카드 결제 예정 · 보유 자산** 네 표와 요약 4칸(총자산·총부채·순자산·월 순현금흐름), **다가오는 주요 출금**(카드 결제일·대출 결제일에서 자동 집계), **자산 비율 막대**, **CSV/JSON 백업·불러오기**를 한 화면에서 다룹니다.

- **자료는 이 저장소에 없습니다.** 표의 실제 금액은 복지모아 서버(`bokjimoa.onrender.com`)의 PostgreSQL(`personal_finance_state` 한 행)에만 있고, 이 공개 저장소의 HTML·JS·CSS 에는 어떤 개인 수치도 두지 않습니다. 코드의 기본값은 **완전히 빈 표**입니다.
- **읽기·쓰기 모두 관리자 인증이 필요합니다.** `GET`/`PUT /api/admin/personal-finance` 는 다른 `/api/admin/*` 와 같은 `requireAdminAuth`(아이디 로그인 HMAC 토큰 또는 `x-sync-key`)를 거칩니다. 비로그인 요청은 401, 토큰 만료는 403 입니다.
- **불러오기**: 탭을 열면 `GET` 으로 저장된 자료를 받아 그립니다. 세션이 없거나 데모(미리보기) 모드면 **탭 자체가 숨겨지고** 화면에 자료가 남지 않습니다(로그아웃·세션 만료 시 `MOA_FINANCE.clear()` 가 메모리와 표를 비웁니다).
- **저장**: 칸을 고치거나 행을 추가·삭제하면 **0.5초 디바운스** 뒤 `PUT` 으로 저장하고, 오른쪽 위 칩이 `저장 중…` → **`클라우드 동기화됨 HH:MM`** 으로 바뀝니다. 저장에 실패하면 칩이 `저장 실패` 로 바뀌고 4·8·12초 뒤 다시 시도합니다. 탭을 닫거나 다른 화면으로 옮길 때(`pagehide`·`visibilitychange`)도 남은 변경을 즉시 밀어 넣습니다.
- **다른 기기와 동기화**: 60초마다(탭이 보이고 편집 중이 아닐 때) 서버의 `updatedAt` 을 확인해 바뀐 자료만 다시 그립니다. `🔄 서버에서 다시 불러오기` 로 즉시 맞출 수도 있습니다. 여러 기기에서 같은 순간에 고치면 마지막 저장이 남습니다(충돌 병합 없음).
- **백업**: `💾 JSON 백업`·`📊 CSV 내보내기`(엑셀 한글 깨짐 없음)·`📂 백업 불러오기`·`↺ 표 비우기`(누르기 전에 자동 백업 파일을 먼저 내려받음). JSON 백업 파일은 예전 `개인재무관리.html` 의 백업과 같은 모양이라 그대로 불러올 수 있습니다.
- 서버 쪽 구현·테스트: `bokjinabi` 저장소의 `lib/personal-finance.js`(모양 검증·240자·300행·256KB 한도), `test/personal-finance.test.js`(비인증 401·틀린 키 403·저장/조회·400·413·CORS 12건).
- 화면 코드는 `assets/js/finance.js` + `assets/css/finance.css` 이고, app.js 는 `MOA_FINANCE.init({ request: apiRequest })` 로 인증 요청 함수만 넘깁니다. 표를 넓게 쓰려고 이 탭에서는 `.layout.is-wide` 로 미리보기 레일을 접습니다.

부장님이 쓰던 엑셀 가계부 사진의 표 구조를 그대로 옮기고, 표를 고칠 때마다 **위쪽 리포트가 즉시 다시 계산**됩니다.

- **① 실시간 자동 분석 리포트** — KPI 6칸(총자산·총부채·순자산·이달 수입−지출·남은 미납 지출·월 이자 부담) + 분석 카드(이달 적자/흑자와 초과근로 반영 후 금액, 고금리 우선 상환 순위, 미납 잔금의 이체일별 내역, 이번 달·다음 달 카드, 재무 건전성(부채비율·이자/수입), 초과근로 예상액, DC 적립 합계).
- **② 월 고정지출·이체** — 종목·금액·이체일·**납입여부(O/미납 토글)**. 이체일이 같은 행마다 **소계 행**(합·잔금·건수)이 자동으로 끼어들고, 맨 아래 **총합 / 잔금(미납 합계) / 이달 적자·흑자 / 수입**이 계산됩니다.
- **③ 수입 · 이번 달 카드 · 다음 달 카드 예정액** — 세 표를 나란히 두고 각각 합계를 자동 계산합니다.
- **④ 부채(대출)** — 종목·잔금·금리·**원금+이자**·원금·이자·만기·남은개월·비고. 이자나 남은개월을 비우면 **잔금×금리÷12**, **만기까지 남은 개월**로 자동 채워지고, 하단에 부채 합계(잔금·가중평균 금리·원리금·원금·이자)가 나옵니다.
- **⑤ 자산** — 종목·매입금액·수량·시세·평균단가·**비중**·**손실/수익**·합계. 수량×시세→합계, 매입÷수량→평균단가, 합계−매입→손익, 합계÷총자산→비중이 자동이고 자산 구성 막대가 함께 그려집니다.
- **⑥ 초과근로 시뮬레이션 · 퇴직금 DC** — 초과근로·8시간초과·야간 시간과 통상시급을 넣으면 **기본 초과임금·연장가산(×0.5)·8시간초과가산(×0.5)·야간가산(×0.5)·합계**가 계산됩니다. DC 적립 내역은 연도별 표(합계 자동).
- **기준일** 칸(표 상단)으로 엑셀을 찍은 날짜를 남길 수 있고, **CSV 내보내기**는 표 7개 + 요약을 모두 담습니다.
- 서버 스키마도 v2 로 올렸습니다(`bokjinabi` `lib/personal-finance.js`, v0.17.0). 예전 v1(`cashflow·loans·cards·assets`) 자료는 **서버가 읽을 때·저장할 때 모두 v2 로 옮겨** 보존합니다.

## 🔌 태블릿 중계 서버 카드 (2026-11-20 · v=31)

포케모아 영역(⑤ 저장·배포)에 **태블릿에서 도는 중계 서버(`relay/server.js` v2.0)** 를 확인하고 갱신하는 카드를 두었습니다.
- **주소** — cloudflared 임시 주소라 `localStorage`(`moa-admin.relayUrl`)에 저장합니다. 기본값은 현재 터널 주소이고, 주소가 바뀌면 칸에 넣고 **주소 저장**. (터널 주소는 태블릿을 다시 켜면 바뀝니다.)
- **상태 확인** — `GET {주소}/health` 로 `status-pill` 에 `온라인 · v2.0` / `오프라인` 과 가동 시간을 보여 줍니다. ⑤ 탭을 열면 조용히 한 번 조회합니다.
- **🔄 최신 버전 업데이트** — `POST {주소}/admin/update` 에 `X-Admin-Token` 을 답니다. 값은 **아이디 로그인 토큰**(HMAC) 또는 저장해 둔 `x-sync-key` 이고, 둘 다 없으면 눌러도 안내만 하고 요청하지 않습니다. 응답이 오면 1.2초 간격으로 `/health` 를 다시 조회해 **새 버전이 응답하는지 확인한 뒤** `업데이트 완료 · v2.0` 으로 바꿉니다(최대 12초).
- v2.0 이전 판(v1.x)은 `access-control-allow-headers` 에 `x-admin-token` 이 없어 브라우저 POST 가 프리플라이트에서 막힙니다. 그때는 카드가 **`업데이트 불가 · v1.x`** 와 함께 “태블릿에서 한 줄 설치가 한 번 필요하다”고 안내합니다(설치 뒤부터 이 버튼으로 갱신).
- 서버 쪽 동작(고정 URL·문법 검사·백업·무중단 재시작)은 [`pokemoa` README 4장](https://github.com/moa-kr/pokemoa#4-실시간-중계--집-태블릿-실재고-v38)과 `relay/server.js` 머리말 주석에 적었습니다.

## 📊 방문 통계 (2026-11-19)

`📊 통계` 탭은 복지모아 서버의 `GET /api/admin/analytics?site=all|pokemoa|bokjimoa&days=1|7|30` 을 아이디 로그인 토큰(또는 `x-sync-key`)으로 부릅니다. 사이트 쪽 수집기(`site-config-loader.js` v4.1)가 화면을 떠날 때 보내는 기록을 서버가 PostgreSQL 에 쌓고, 이 화면은 집계 결과만 받습니다. **IP·쿠키·이메일 같은 개인 식별 값은 저장하지 않습니다**(익명 세션 ID만). 어드민 미리보기(iframe·`?moa_preview=`)와 localhost 는 수집 대상이 아닙니다. 데모 모드에서는 서버 자료를 불러오지 않고 로그인 안내만 보여 줍니다.

**실제 사이트에 반영되는 값**(2026-11-18 연결, 2026-11-19 문구 전면 확장): 공지 바, 팝업, 탭 순서·노출·이름표, **탭 안 섹션 순서·노출·제목·본문 문단**, 그리고 `copy` 의 모든 문구 — 포켓몬카드모아 171개(히어로 가격 박스·시세 안내·오프라인 바로가기 카드·지도 툴바 라벨·시세 통합 조회 링크 7개 이름/설명·환율 위젯·일정 표 머리글까지), 회사복지모아 65개(통계 라벨·회사 카드 버튼·랭킹 기준·계산기 입력 라벨까지). 바뀌는 자리 전체 목록은 [`SCHEMA.md`](SCHEMA.md) 의 ‘문구 키 전체 목록’에 있습니다. `cards`(현황 카드)와 `theme`(강조색)는 미리보기 전용입니다.

**탭 안 섹션 편집**(② 화면): 위쪽 탭 칩에서 탭을 고르면 그 탭 패널 안의 섹션만 나옵니다. ✎ 를 펼치면 그 섹션의 모든 문구 칸(`copyKeys`)이 대표 문구·세부 문구로 나뉘어 함께 열리고, ③ 문구 화면의 같은 섹션 묶음과 실시간으로 동기화됩니다. 포케모아는 5개 탭 15개 섹션(지도 상태 안내·공식 채널·첫 화면·정가 구매처·다른 박스·오프라인·인기 카드팩·오늘의 체크·카드 뉴스·발매 일정·환율·거래가 조회·수록 카드·FAQ·팝수), 회사복지모아는 4개 탭 11개 섹션(홈 5 + 주제별 TOP·계산기·비교 각 2)입니다. 섹션마다 제목·표제·설명·링크는 `copy` 문구로, 본문은 `navigation.sections[].body` 로 저장되고, 사이트 로더(v3)가 같은 탭 안에서 순서를 맞추고 본문을 섹션 아래에 그립니다.
